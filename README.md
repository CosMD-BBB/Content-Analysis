# Content Studio (ตัวอย่าง)

ระบบจัดการคอนเทนต์ของทีม: วางตารางงาน, ขั้นตอนอนุมัติ, กดเผยแพร่ไปหลายช่องทาง, ดึงรายงานผล และเก็บรายการโปรด

> ตอนนี้เป็น **prototype หน้าเว็บอย่างเดียว** ใช้ข้อมูลจำลอง การเชื่อมต่อ API และการโพสต์เป็นการจำลองขั้นตอน
> สิ่งที่กดในหน้าเว็บจะเก็บไว้ใน `localStorage` ของเบราว์เซอร์ที่เปิดเท่านั้น

## เปิดดู

เปิดไฟล์ `prototype/index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
(`prototype/content-studio.html` คือไฟล์ต้นฉบับเดียวกัน ที่ใช้เผยแพร่เป็นลิงก์)

### กติกาเวลากดเผยแพร่

แต่ละช่องทางของคอนเทนต์ชิ้นหนึ่งจะได้ผลเป็นอย่างใดอย่างหนึ่ง:

1. **โพสต์อัตโนมัติ**: เชื่อมต่อแล้ว และ API รองรับประเภทงานนั้น
2. **ส่งเป็นแบบร่าง**: เช่น TikTok ที่ยังไม่ผ่าน audit ต้องไปกดโพสต์ในแอป
3. **ต้องโพสต์เอง**: ไม่มี API, ยังไม่เชื่อมต่อบัญชี หรือ API ไม่รองรับประเภทงาน

ข้อ 2 และ 3 จะเข้าแท็บ "ต้องโพสต์เอง" พร้อมปุ่มคัดลอกแคปชัน เมื่อโพสต์เสร็จให้วางลิงก์โพสต์เพื่อปิดงาน
ถ้าช่องทางนั้นดึงสถิติผ่าน API ได้ ระบบจะใช้ลิงก์นั้นติดตามผลต่อ ถ้าดึงไม่ได้ จะขึ้นในรายงานว่า "ตัวเลขที่ยังขาด" ให้กรอกเอง

## ถ้าจะทำเป็นระบบจริง (ข้อเสนอ)

- **Frontend**: Next.js (React) + Tailwind
- **Backend/DB**: PostgreSQL (เช่น Supabase) เก็บ users, roles, contents, channel_accounts, publish_jobs, metrics_snapshots
- **Login**: Google Workspace / อีเมลบริษัท แล้วตรวจสิทธิ์ตามบทบาทฝั่งเซิร์ฟเวอร์ทุกครั้ง (ไม่พึ่งการซ่อนปุ่มอย่างเดียว)
- **เชื่อมต่อช่องทาง**: OAuth ของแต่ละแพลตฟอร์ม เก็บ token แบบเข้ารหัสฝั่งเซิร์ฟเวอร์ และต่ออายุอัตโนมัติ
- **โพสต์ตามเวลา**: job queue (เช่น cron + worker) ลองใหม่อัตโนมัติเมื่อ API ล้มเหลว และแจ้งเตือนเมื่อพังถาวร
- **ดึงสถิติ**: งานรันทุก 6 ชั่วโมง เก็บเป็น snapshot รายวัน เพื่อทำกราฟย้อนหลังได้
- **แจ้งเตือน**: LINE / อีเมล เมื่อมีงานรออนุมัติ ถูกขอแก้ หรือมีงานต้องโพสต์เอง

## เลือกเซิร์ฟเวอร์ (คำแนะนำ)

ระบบต้องการ: เว็บ + worker (โพสต์ตามเวลา/ดึงสถิติ) + PostgreSQL + ที่เก็บรูปและวิดีโอ
โค้ดจะรันด้วย Docker จึงย้ายเจ้าได้ภายหลัง ราคาด้านล่างเป็นราคาโดยประมาณ ต้องเช็กหน้าราคาของผู้ให้บริการอีกครั้ง

| ทางเลือก | เหมาะกับ | ค่าใช้จ่ายโดยประมาณ/เดือน |
|---|---|---|
| **Railway** (แนะนำเริ่มต้น) | ไม่มีคนดูแลเซิร์ฟเวอร์ประจำ · กด deploy จาก GitHub อัตโนมัติ · มี Postgres ในที่เดียว | แผน Pro $20 (รวมค่าใช้งาน $20 แรก) ใช้จริงราว $20–35 |
| **DigitalOcean** (Singapore) | อยากเช่าเซิร์ฟเวอร์เอง คุมได้เต็มที่ | Droplet ~$12–24 + Managed PostgreSQL เริ่ม ~$15 |
| VPS เครื่องเดียวรันทุกอย่าง | ประหยัดสุด แต่ต้องดูแลการสำรองข้อมูลเอง | ~$6–12 |
| ผู้ให้บริการในไทย | ต้องการเก็บข้อมูลในไทย / จ่ายเป็นบาทพร้อมใบกำกับภาษี | แล้วแต่เจ้า |
